Documentation

Everything you need to install MultiWealth, connect your accounts, and get a complete picture of your wealth. This guide walks you through each module step by step.

Prerequisites

Before installing, make sure you have the following installed on your machine:

ToolVersionWhy
Node.js20+Runs both the frontend and backend
PostgreSQL14+Stores all your financial data locally
Python3.9+Required for PDF statement parsing
💡
macOS tipInstall all three via Homebrew: brew install node postgresql python

Installation

1. Clone the repository

bash
git clone git@github.com:Halkhoori2000/MultiWealth.git   (private beta - request access)
cd MultiWealth

2. Install dependencies

bash
# Frontend dependencies
npm install

# Backend dependencies
cd server && npm install && cd ..

3. Configure environment variables

Create a .env file in the project root:

.env (root)
VITE_API_BASE_URL=http://localhost:3001
VITE_API_URL=http://localhost:3001

Create a .env file inside the server/ folder:

.env (server/)
DATABASE_URL="postgresql://user:password@localhost:5432/multiwealth"
⚠️
Replace credentialsSwap user and password with your actual PostgreSQL username and password. Run psql -U postgres to check what credentials you have.

4. Set up the database

bash
cd server && npx prisma db push && cd ..

This creates all the required tables in your PostgreSQL database automatically.

First Launch

Start the backend and frontend in two separate terminal windows:

Terminal 1 — Backend
cd server && npm run dev
Terminal 2 — Frontend
npm run dev

Open http://localhost:5173 in your browser. You'll see the MultiWealth dashboard — empty for now.

ℹ️
Keep both terminals runningThe frontend talks to the backend on port 3001. Both need to be running at the same time for the app to work.

Add a Bank Account

Bank accounts are the foundation of MultiWealth. Each account tracks its balance, statement history, and transactions.

1
Go to the Finance page
Click Finance in the left sidebar. You'll see your bank accounts grouped by bank.
2
Click "Add Account"
Hit the + Add Account button in the top-right corner. A drawer slides in from the right.
3
Fill in the details
Select your bank, account type (Current, Savings, Credit Card, Loan), enter the account name, and the current balance. MultiWealth auto-detects the bank brand and color.
4
Save
Click Save. The account appears in your Finance page instantly, grouped under its bank.

Repeat for all your accounts across RAKBank, FAB, ADCB, Emirates NBD, Mashreq, and Citi.

Import Statements

The fastest way to populate your transaction history is to import bank statements. MultiWealth supports both PDF and CSV formats.

1
Download your statement
Log in to your bank's online portal and download your statement as a PDF or CSV. Any date range works.
2
Open the account
Click on the account you want to import into. This opens the Account Detail panel on the right.
3
Click "Import Statement"
Find the Import Statement button in the account panel. A file picker appears.
4
Drop your file
Drag and drop the PDF or CSV file onto the drop zone, or click to browse. MultiWealth auto-detects the bank format, statement period, and parses all transactions.
5
Review and confirm
A preview shows the detected transactions. Duplicates (transactions already in the system) are highlighted and excluded automatically. Click Import to save.
💡
Import multiple periodsYou can import statements from different months on the same account. Duplicates are automatically detected and skipped, so there's no risk of double-counting.

Transactions

Every imported or manually added transaction appears in the Transactions list. You can filter, search, and categorize them.

  • Categories — Assign a category (Groceries, Dining, Transport, etc.) to each transaction
  • Payees — Tag the merchant or sender for easy grouping
  • Notes — Add a private note to any transaction
  • Manual entry — Click + Add Transaction to log a cash payment or transfer not captured by a statement
  • Filters — Filter by date range, account, category, or amount

Add a Broker

Brokers group your investment holdings. Add one broker per platform you use.

1
Go to Investments
Click Investments in the left sidebar.
2
Add a Broker
Click + Add Broker. Enter the broker name (e.g. Saxo Bank, Binance, Al Ramz) and currency.
3
Save
The broker appears in your Investments page. Now you can add holdings inside it.

Add Holdings

Each holding is an individual stock, ETF, crypto, or fund position under a broker.

1
Open a broker
Click on the broker row to expand it.
2
Add a Holding
Click + Add Holding. Enter the ticker symbol (e.g. AAPL, BTC, VTI), asset type, quantity, and average cost.
3
View performance
Once saved, the holding shows your quantity, average cost, current value, and gain/loss.

Investment Transaction History

Log every buy, sell, dividend, and interest event for accurate cost-basis tracking.

  • Click any holding, then Add Transaction
  • Choose the type: Buy, Sell, Dividend, or Interest
  • Enter the date, quantity, and price per unit
  • Your average cost and total P&L update automatically

Add a Property

Track your real estate portfolio with full detail — purchase price, current value, equity, leases, and milestones.

1
Go to Properties
Click Properties in the left sidebar.
2
Click "Add Property"
Enter the property name, address, purchase price, current estimated value, and type (apartment, villa, off-plan, etc.).
3
Add leases (optional)
If the property is rented out, add a lease with the tenant name, rent amount, start and end date. MultiWealth tracks rental income automatically.
4
Add payment milestones (off-plan)
For off-plan properties, add each payment milestone with its due date and amount. Upcoming payments appear on your dashboard.

Other Assets

Track vehicles, valuables, cash holdings, and any other asset class that contributes to your net worth.

  • Go to Assets in the sidebar
  • Click + Add Asset and choose a type: Vehicle, Valuable, Cash, or Custom
  • Enter the name, current value, and optional purchase price
  • The asset is immediately reflected in your net worth total

Goals

Set financial goals and track progress over time.

1
Go to Goals in the sidebar
Click Goals from the left navigation.
2
Create a Goal
Click + Add Goal. Enter a name (e.g. "Emergency Fund"), target amount, and target date.
3
Track progress
Update the current saved amount over time. A progress bar shows how close you are to your target.

Monthly Budget

Set a monthly spending plan by category and monitor actual spend against it.

  • Go to Goals → Monthly Budget
  • Set your estimated monthly income
  • Allocate a budget to each spending category (Groceries, Dining, Transport, etc.)
  • As transactions come in, actual spend is tracked automatically against each category limit
💡
Budget resets monthlyThe budget view always shows the current calendar month. Import your latest statement at the start of each month to keep it up to date.

Tips & Shortcuts

  • Import often — Download and import statements monthly to keep your net worth accurate
  • Start with banking — Add all your bank accounts first, then investments, then properties
  • Duplicate detection is automatic — You can safely re-import the same statement; duplicates are skipped
  • Everything is local — Your data lives in PostgreSQL on your machine. Back it up with pg_dump multiwealth > backup.sql
  • Restore a backup — psql multiwealth < backup.sql
